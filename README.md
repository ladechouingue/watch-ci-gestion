# Watch Côte d'Ivoire - Gestion

Outil de gestion (stock, commandes, clients, dépenses) pour watchcotedivoire.com.
PHP + SQLite, aucune configuration. Les données (dossier `data`) et les photos (dossier `uploads`) restent sur l'hébergement et ne sont jamais envoyées ici.

Mise à jour : dans l'outil, bouton « Mettre à jour ». Le numéro de version est dans le fichier `VERSION`.
